KRAKE User Manual

Use this guide to navigate the KRAKE web pages and the physical LCD menu.

Getting Started

  1. Power on the KRAKE device and wait for the LCD home screen to appear.
  2. Connect your phone or computer to the same network as the device.
  3. Open the device URL or IP address shown on the LCD or on the Home page.
  4. Use the menu button in the top-right corner of the web page to open the side menu.

Tip: The serial number shown in the web UI is the device identifier used in MQTT topics. It is usually based on the device MAC address.

Web Menu Navigation

The browser menu is opened from the button in the top-right corner.

Basic User Pages

  • Home: Shows serial number, URL, IP address, MAC address, WiFi signal, uptime, MQTT connection status, firmware version, build time, and live LCD output.
  • GDT Track Record: Shows device reporting history and lets you filter between all devices, reporting devices, and non-reporting devices.
  • User Manual: Opens this guide.

Admin Pages

  • Settings: Configure WiFi, mute/unmute the device, save sound defaults, and manage MQTT broker/topic settings.
  • Firmware Update: Opens the firmware update page for loading new device firmware.

Developer Pages

  • PMD Web UI: Sends PMD alarm messages to selected saved MQTT topics.
  • Factory Test / Developer Monitor: Shows live monitor output for testing and diagnostics.
  • MQTT Device Monitor: Tracks devices by MAC-based MQTT topics and connection activity.
  • Electrical Test History: Records and reviews powered and unpowered electrical test results.

Developer Mode Unlock

  1. Open the side menu.
  2. Select Unlock Developer Mode.
  3. Enter the developer password.
  4. Select Unlock.

When developer mode is unlocked, the developer pages appear in the side menu. Use Lock Developer Tools to hide them again.

Physical LCD Controls

Use the rotary encoder and the mute button to control the device without a browser.

Rotary Encoder

  • Rotate clockwise: Move down or to the next option.
  • Rotate counter-clockwise: Move up or to the previous option.
  • Press: Select the highlighted item.
  • Double press or long press: Go back when supported by the current menu.

Mute Button

  • Press the mute button once to mute the alarm audio using the configured mute timeout.
  • Press it again while muted to unmute the device.

The settings menu returns to the main LCD page automatically after about two minutes without interaction.

LCD Home Screen

The home screen is the normal operating screen.

  • Rotate the encoder to move focus between available home-screen icons and alarm pages.
  • Press the encoder to open the focused item.
  • If an alarm is active, rotating or pressing the encoder can open the alarm action selector.

Home-Screen Icons

  • WiFi: Opens WiFi status and web UI information.
  • Broker: Lets you choose the MQTT broker profile.
  • Mute: Opens quick mute controls.
  • Settings: Opens the full settings menu.

Alarm Actions

When an alarm is active, use the encoder to choose the response.

  1. Rotate or press the encoder until the alarm action selector appears.
  2. Rotate to highlight the desired action.
  3. Press the encoder to send the selected action.
  • Shelve: Temporarily shelves the alarm.
  • Acknowledge: Confirms that the alarm has been seen.
  • Dismiss: Clears the current alarm from the device display.
  • Complete: Marks the alarm as completed.

Settings Menu

Open Settings from the LCD home screen or by pressing the encoder when no other action is selected.

Main Settings Items

  • Info: Shows device information.
  • WiFi: Opens WiFi status and the web UI address.
  • Volume: Sets the audio volume from 1% to 100%.
  • Alarm Repeat: Sets the repeat interval from 1 to 300 seconds.
  • Mute Duration: Sets or applies mute behavior.
  • Developer Mode: Opens advanced broker, COM, diagnostics, and WiFi credential options.
  • Reset Device: Restarts the device after confirmation.
  • Back: Returns to the main LCD page.

Changing a Setting

  1. Rotate to highlight the setting.
  2. Press the encoder to enter or edit it.
  3. Rotate to change the value or option.
  4. Press the encoder to save or run the selected action.
  5. Select Back to return to the previous screen.

Mute Duration Menu

  • Set Duration: Choose a timed mute duration from 1 to 60 minutes.
  • Mute Now: Mutes immediately using the selected duration.
  • Mute Infinite: Mutes until the device is manually unmuted or receives an unmute command.
  • Unmute: Turns alarm audio back on.
  • Back: Returns to Settings.

Developer Mode Menu

Use these options only when configuring, testing, or servicing the device.

  • Broker: Select Krake PubInv or Saved Custom. Custom broker details are configured from the web Settings page.
  • COM Setup: Configure baud rate, serial format, and flow control, then select Save. Select Back to exit without saving changes.
  • Diagnostics: Shows device information useful for troubleshooting.
  • Clear WiFi Creds: Clears saved WiFi credentials after confirmation and restarts the WiFi setup flow.
  • Back: Returns to Settings.

Common Tasks

Check Device Status

  1. Open the device web page.
  2. Go to Home.
  3. Review IP, WiFi RSSI, MQTT status, firmware version, uptime, and live LCD output.

Change MQTT Broker

  1. Open the LCD Settings menu.
  2. Go to Developer Mode, then Broker.
  3. Select Krake PubInv or Saved Custom.

Configure a Custom Broker

  1. Open the web side menu.
  2. Go to Settings.
  3. Enter the custom broker host, username, password, and topics.
  4. Select Save MQTT Config.
  5. Use the LCD Broker menu to select Saved Custom.

Reset WiFi Credentials

  1. Open Settings, then Developer Mode.
  2. Select Clear WiFi Creds.
  3. Select Confirm Clear.
  4. Wait for the device to restart and follow the WiFi setup flow.
